
## Style Decisions

- La dirección final queda definida como **manual técnico cinematográfico premium**: páginas editoriales en papel frío, superficies técnicas en navy profundo, azul eléctrico para acciones y progreso, y ámbar cálido solo para metadatos, advertencias y acentos de oficio.
- El símbolo de marca combina automatización y producción de video, y se repite en cabecera, hero y pie para evitar que el producto se perciba como documentación genérica.
- Los encabezados usan Space Grotesk y el texto de lectura usa DM Sans; JetBrains Mono se reserva para comandos y configuración.
- Cada bloque principal incluye una señal del pipeline prompt-a-video: lockup, frame stack, líneas de conexión, etiquetas de terminal, badges de formato o progreso por pasos.
- Se conserva una navegación lateral como índice contextual y una única lectura continua para que la consulta rápida no rompa la narrativa.
- El azul tecnológico #007BFF identifica acción, progreso y recomendación; el ámbar #E8A24A identifica metadata, notas y atención.
- No se añaden testimonios, reseñas ni datos de usuarios inventados. El sitio es frontend-only y enlaza a las fuentes oficiales.
- La experiencia móvil transforma el índice lateral en un panel colapsable y mantiene el mismo orden de lectura.
- Pregunta de control para futuras ediciones: ¿esta decisión refuerza o diluye la filosofía profesional y elegante?

### Dirección elegida

**Profesional y elegante**, reinterpretada como un manual técnico cinematográfico premium. El sitio no imita un README plano: traduce el contenido a una experiencia editorial para creadores que necesitan decidir, instalar y automatizar con rapidez.

### Voz y posicionamiento

El manual habla de forma directa, práctica y empoderadora. Titulares como «De una idea a un video» y CTA como «Comenzar guía» hacen tangible la transformación sin prometer resultados irreales.

### Motivo recurrente

El pipeline de cuatro nodos —prompt, guion, montaje y export— funciona como hilo visual del sitio, conectando la identidad de MoneyPrinterTurbo con su principal promesa de producto: convertir una idea en una pieza audiovisual.
